# starmap-test

starmap-test checks that an application's `starmap.toml` declares exactly
the environment variables its code reads. An application calls the check
from an ordinary `#[test]`, as a dev-dependency.

The crate has no items yet. The repository's
[README](https://github.com/crumbkit/starmap) describes the project.
