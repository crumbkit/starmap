Check that starmap.toml follows every rule of the file, and that it declares every variable that src reads

Usage: starmap check [OPTIONS]

Options:
      --spec <FILE>  Read the spec from this file [default: starmap.toml]
      --src <DIR>    Scan this source directory, in place of the default directories; repeat the option to scan several
  -h, --help         Print help (see more with '--help')

Examples:
  starmap check
  starmap check --json
  starmap check --src src/books

Effects: read-only, closed-world.
Global flags: --json, --no-input. `starmap check --help` describes them.
