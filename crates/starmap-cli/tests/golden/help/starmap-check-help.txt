Check that starmap.toml follows every rule of the file, and that it declares every variable that src reads.

check counts a literal name passed to var or var_os, a #[starmap("NAME")] field, and clap's env argument, as in #[arg(env = "NAME")]; a bare clap env reads the upper-case form of its field's name. It does not count a name held in a constant.

A read whose name format! builds from a name, an underscore and one trailing placeholder, such as format!("SHELF_DB_URL_{region}"), reads a member of that family, and check fails when the file declares no such family. check passes on any other format! name and names the place of each one it cannot resolve.

check also fails when the clippy.toml that Clippy reads for a crate whose source directory holds a .rs file lacks a disallowed-methods entry for std::env::var, var_os, vars or vars_os. starmap init --clippy adds the entries.

Usage: starmap check [OPTIONS]

Options:
      --spec <FILE>
          Read the spec from this file
          
          [default: starmap.toml]

      --json
          Print the result as a JSON document. The default prints text.

      --no-input
          Fail instead of asking a question

  -h, --help
          Print help (see a summary with '-h')

Examples:
  starmap check
          Check starmap.toml in the current directory

  starmap check --json
          Print the result of the check as JSON

Effects: read-only, closed-world.
