Run a program with the environment that starmap.toml declares.

run resolves every variable, checks the values and starts the program with each declared variable set or removed. A value comes from --set, then the shell, then .env beside the spec or the file that a pointer names, then a setting's path bind, then the default. A secret comes from its bind, or from the shell or the Keychain when it has none; at a terminal, run asks for a missing one and offers to save it to the Keychain. .env and --set never give a secret.

The program also inherits every other variable of the shell, unless --only-declared is passed. With --only-declared, the program receives each declared variable that has a value, each member of a declared family that is set, and the built-in variables that the operating system and common tools need, such as PATH and HOME, and a read of any other variable finds it unset. starmap explain lists the built-in variables.

Usage: starmap run [OPTIONS] -- <PROGRAM>...

Arguments:
  <PROGRAM>...
          The program to run and its arguments, after --

Options:
      --spec <FILE>
          Read the spec from this file
          
          [default: starmap.toml]

      --workspace <NAME>
          Name the Keychain items of this checkout after this workspace; default: the checkout's directory name

      --set <NAME=VALUE>
          Give a setting or inherited variable this value for this run, as NAME=VALUE; repeat it for more

      --only-declared
          Start the program with only the declared variables and the built-in ones that starmap explain lists

      --json
          Print the result as a JSON document. The default prints text.

      --fields <FIELD>
          Print only these comma-separated fields, in this order. The default prints the compact columns.

      --long
          Add the long columns after the compact ones. The default prints only the compact columns.

      --full
          With --json, print every field of every row. The default prints only the fields of the columns.

      --no-input
          Fail instead of asking a question

  -h, --help
          Print help (see a summary with '-h')

Examples:
  starmap run -- cargo run
          Run the app with the environment that starmap.toml declares

  starmap run --set SHELF_DEBUG=true -- cargo run
          Run the app with one setting changed for this run

  starmap run --only-declared -- cargo test
          Run the tests with only the declared and built-in variables, so a read of an undeclared one finds it unset

Effects: additive, not idempotent, closed-world.
Exit code: the command passes on the exit code of the program after --.
