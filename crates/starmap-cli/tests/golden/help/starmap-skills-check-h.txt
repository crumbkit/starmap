Check that each installed copy of starmap's skill matches this starmap

Usage: starmap skills check [OPTIONS]

Options:
      --dir <DIR>  Check this skills directory in place of the agent skills directories
  -h, --help       Print help (see more with '--help')

Examples:
  starmap skills check

Effects: read-only, closed-world.
Rows: the default text lists only the rows that report a problem, and --long, --fields or --json lists every row.
Global flags: --json, --fields <FIELD>, --long, --full, --no-input. `starmap skills check --help` describes them.
Next: starmap skills check --help explains each column.
