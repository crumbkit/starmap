List a branch of starmap's commands with their arguments, examples and columns

Usage: starmap commands list [OPTIONS] [PATH]...

Arguments:
  [PATH]...  The names of the commands below the root that lead to the branch, such as `books list`

Options:
      --limit <N>  Print at most this many rows [default: 25]
      --all        Print every row
  -h, --help       Print help (see more with '--help')

Examples:
  starmap commands list

Effects: read-only, closed-world.
Global flags: --json, --fields <FIELD>, --full. `starmap commands list --help` describes them.
Next: starmap commands list --help explains each column.
