Check that starmap's installed completion file matches this starmap

Usage: starmap completion check [OPTIONS]

Options:
      --shell <SHELL>
          Check the file of this shell in place of the one that SHELL names

          Possible values:
          - bash:       Bash, which loads a completion file from bash-completion's user directory
          - elvish:     Elvish, which has no completion directory
          - fish:       Fish, which loads a completion file from its completions directory
          - powershell: PowerShell, which has no completion directory
          - zsh:        Zsh, which loads a completion function from a directory on `fpath`

      --json
          Print the result as a JSON document. The default prints text.

      --fields <FIELD>
          Print only these comma-separated fields, in this order. The default prints the compact columns.

      --long
          Add the long columns after the compact ones. The default prints only the compact columns.

      --full
          With --json, print every field of every row. The default prints only the fields of the columns.

      --no-input
          Fail instead of asking a question

  -h, --help
          Print help (see a summary with '-h')

Examples:
  starmap completion check --shell zsh
          Report zsh's completion file when it is missing or differs

Columns:
  state   Whether the file holds the script that install writes: missing, differs, unreadable, linked or current.
  shell   The shell: bash, elvish, fish, powershell or zsh.
  path    The completion file that was checked. When the file is a link to a file that install wrote, the path of that file.
  reason  Why the file differs, cannot be read or is linked, such as `linked to /src/shelf/shelf.fish`, or null.

Effects: read-only, closed-world.
Rows: the default text lists only the rows that report a problem, and --long, --fields or --json lists every row.
