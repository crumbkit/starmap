Write, check, explain and run the environment variables that an application declares in starmap.toml

Usage: starmap [OPTIONS] <COMMAND>

Write and check starmap.toml
  init        Write starmap.toml with a guess for each variable that src reads
  check       Check that starmap.toml follows every rule of the file, and that it declares every variable that src reads

Run a program with its environment
  run         Run a program with the environment that starmap.toml declares

Read the variables
  explain     Describe each declared variable and the value it has in this shell
  diff        List each variable that was added, changed or removed since a git revision's spec

Explore commands
  commands    Explore starmap's commands
  schemas     Explore the JSON documents that starmap prints
  self        Review starmap's own use

Install starmap's skill
  skills      Give coding agents starmap's skill

Set up shell completion
  completion  Set up starmap's completion in a shell

Options:
      --json
          Print the result as a JSON document. The default prints text.

      --fields <FIELD>
          Print only these comma-separated fields, in this order. The default prints the compact columns.

      --long
          Add the long columns after the compact ones. The default prints only the compact columns.

      --full
          With --json, print every field of every row. The default prints only the fields of the columns.

      --no-input
          Fail instead of asking a question

  -h, --help
          Print help (see a summary with '-h')

  -V, --version
          Print version

Topics: exit-codes. `starmap help <TOPIC>` prints one.
