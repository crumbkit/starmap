Print the JSON Schema of each document

Usage: starmap schemas show [OPTIONS] <ID>...

Arguments:
  <ID>...  The ids of the documents that `schemas list` lists, separated by spaces

Options:
  -h, --help  Print help (see more with '--help')

Examples:
  starmap schemas show starmap/init/v1

Effects: read-only, closed-world.
Global flags: --json, --fields <FIELD>, --full, --no-input. `starmap schemas show --help` describes them.
Next: starmap schemas show --help explains each column.
