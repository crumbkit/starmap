Give coding agents starmap's skill

Usage: starmap skills [OPTIONS] <COMMAND>

Commands:
  install  Install starmap's skill into each agent skills directory that exists
  check    Check that each installed copy of starmap's skill matches this starmap
  print    Print starmap's skill

Options:
  -h, --help  Print help (see more with '--help')

Global flags: --json, --fields <FIELD>, --long, --full, --no-input. `starmap skills --help` describes them.
Next: starmap skills <COMMAND> -h
