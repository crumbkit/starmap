Explore the JSON documents that starmap prints

Usage: starmap schemas [OPTIONS] <COMMAND>

Commands:
  list  List the JSON documents that starmap prints, with a description of each
  show  Print the JSON Schema of each document

Options:
  -h, --help  Print help (see more with '--help')

Global flags: --json, --fields <FIELD>, --long, --full, --no-input. `starmap schemas --help` describes them.
