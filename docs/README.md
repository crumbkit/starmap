# starmap documentation

- [Conformance cases](../conformance/README.md) lets another
  implementation of the `starmap.toml` format prove that it parses, refuses,
  writes and checks files as starmap does, and gives the layout of the
  cases.
- [Decisions](decisions/README.md) records each choice that shapes
  starmap's code or what adopters must accept, with the alternatives that
  were considered.
- [Glossary](glossary.md) names each starmap concept once, with its spelling
  in `starmap.toml` and in the Rust API.
- [Standards](standards/README.md) says which Rust standards starmap
  follows and where the adoption map records how.
